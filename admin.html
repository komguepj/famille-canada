Outil du webmestre

Famille Étoile-des-Îles — gestion du registre par formulaire → fichier (aucune base de données).

Comment ça marche

  1. Remplissez un formulaire ci-dessous (nouvelle sous-famille, nouveau membre, ou nouvelle photo).
  2. Chaque ajout met à jour l'aperçu du registre, chargé en mémoire dans cette page.
  3. Cliquez sur « Télécharger family-data.json » pour obtenir le fichier mis à jour.
  4. Remplacez le fichier family-data.json existant sur l'hébergement du site (gestionnaire de fichiers, FTP, ou dépôt GitHub selon votre hébergeur). Le site public se met à jour automatiquement, sans autre modification.

🔗 Liens automatiques : chaque lien saisi génère aussi son réciproque — indiquez que A est l'époux de B, et B devient automatiquement l'épouse (ou l'époux) de A ; indiquez que A est le père de B, et B devient automatiquement fils/fille de A ; idem pour oncle/tante ↔ neveu/nièce. De plus, un lien frère/sœur se propage par transitivité (A frère de B, B frère de C → A frère de C), et un lien cousin(e)/oncle-tante/neveu-nièce s'étend automatiquement à toute la fratrie. Pour que le bon mot soit choisi (cousin/cousine, fils/fille…), indiquez le sexe de chaque membre.

Registre chargé : 0 sous-famille(s), 0 membre(s), 0 photo(s) d'événement.
